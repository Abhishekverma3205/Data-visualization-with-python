# Data Visualization with Python

A comprehensive collection of data visualization projects and tutorials using Python libraries like **Matplotlib**, **Pandas**, and **NumPy**.

## 📚 Repository Contents

### Jupyter Notebooks

#### Challenges & Projects
- **Challenge_1_DV.ipynb** - First data visualization challenge
- **Challenge_2_DV.ipynb** - Second data visualization challenge  
- **Challenge_3_DV (1).ipynb** - Third data visualization challenge
- **Challenge.ipynb** - Additional challenge exercises

#### Visualization Types
- **Scatter Plot.ipynb** - Scatter plot examples and techniques
- **Pie Chart.ipynb** - Pie chart creation and customization
- **Waffle Chart.ipynb** - Waffle chart implementations
- **pandas.ipynb** - Data visualization using Pandas
- **outliers.ipynb** - Identifying and visualizing outliers

#### Learning Materials
- **Numpy.py** - NumPy fundamentals for numerical computing

### Python Scripts

#### Matplotlib Examples
- **Histogram.py** - Creating histograms
- **Line plot.py** - Line plot examples
- **Matplotlib Box graph.py** - Box plot implementations
- **Matplotlib area plot.py** - Area plot visualizations

## 🛠️ Technologies Used

- **Matplotlib** - Static, animated, and interactive visualizations

- **Jupyter Notebooks** - Interactive coding environment

## 📖 Getting Started

### Prerequisites
```bash
pip install matplotlib pandas numpy jupyter
```

### Running the Code

1. Clone the repository:
```bash
git clone https://github.com/Abhishekverma3205/Data-visualization-with-python.git
cd Data-visualization-with-python
```

2. Launch Jupyter Notebook:
```bash
jupyter notebook
```

3. Open any `.ipynb` file to explore the examples and challenges

4. Run individual Python scripts:
```bash
python Histogram.py
python "Line plot.py"
```
